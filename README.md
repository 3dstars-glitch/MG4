## Devlog
Explain how the FloatAnimation script works to animate the fish food GameObjects up and down. Make sure to mention the Start() and Update() methods and _up and _timer variables. You can ignore the StopAnimation() method.

The FloatAnimation script works to animate the fish food objects up and down by using start to set the _timer which flips which direction the food goes when it hits 0 by using _up and !_up which Update reads and uses to determine which way it goes.
